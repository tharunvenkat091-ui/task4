▣

Responsive Images

Images stay inside their containers using flexible sizing and max-width rules.

MOBILE-FIRST THINKING

Built to prevent horizontal scrolling

The page uses a responsive navigation, stacked content sections, scalable typography and flexible spacing. At 768px and below, the desktop columns automatically become a single mobile column.

  • Responsive navigation
  • Stacked mobile layout
  • Scalable fonts and spacing
  • Mobile-friendly buttons
@media (max-width: 768px) {
  .hero-content {
    flex-direction: column;
  }

  .nav-links {
    flex-direction: column;
  }

  img {
    max-width: 100%;
  }
}
