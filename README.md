# Task 4 - Responsive Web Design

A beginner-friendly responsive website created for the internship Task 4:
**Make a Website Mobile-Friendly Using CSS Media Queries.**

## Technologies
- HTML5
- CSS3
- Flexbox
- CSS Grid
- CSS Media Queries

## Responsive Features
- Desktop and mobile layouts
- Navigation changes to a vertical layout below 768px
- Two-column hero/about sections stack vertically on mobile
- Feature cards become one column
- Responsive typography using `clamp()`
- Responsive container widths
- No horizontal page overflow
- Mobile-friendly buttons and spacing
- Viewport meta tag included

## How to Run
1. Download or clone this repository.
2. Open the folder in VS Code.
3. Open `index.html` in a browser.
4. For testing, open Chrome DevTools with `F12`.
5. Click the Device Toolbar icon.
6. Test different mobile sizes such as 375px, 390px, 412px and 768px.
